# 終電のあと / After the Last Train

灯りを持って、雨の深夜の街を歩き続けるブラウザ上の3D体験です。
何もしなくても、ネオン街 → 住宅街 → 線路沿いを自動で歩き、途切れずにループします。
線路沿いの終わりでは踏切で立ち止まり、電車が通り過ぎるのを待ってから渡ります。

- 公開URL: https://haloyukka.github.io/after-the-last-train/
- 要件定義書: [docs/requirements.md](docs/requirements.md)

## 操作

何もしなくても歩き続けます。操作をやめてしばらくすると、自動歩行の状態に戻ります。

| 操作 | PC | スマホ |
| --- | --- | --- |
| 見回す | ドラッグ | 横スワイプ |
| 速さを変える | ↑↓ / W・S / ホイール | 縦スワイプ（上で速く、下でゆっくり） |
| 立ち止まる | スペース（もう一度で歩き出す） | 長押し（押している間） |
| 左右に寄る | ←→ / A・D | 画面の左右の端をタップ |

画面右下のボタンで、音の入・切と操作説明の表示ができます。

## 画質

端末に合わせて「高・中・低」の3段階を使い分け、コマ数が足りないときは自動で1段階ずつ下げます。
`?q=high` `?q=mid` `?q=low` をURLへ付けると固定できます。

## 手元で動かす

ビルドは不要です。ESモジュールはファイルを直接開くと動かないため、簡易サーバーを使います。

```sh
python -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開きます。
`?u=0.5` のようにURLへ付けると、道筋の途中（0〜1）から始められます。

## 構成

```
index.html        画面の枠、読み込み画面、importmap
og.jpg            共有用画像（実際の画面を撮ったもの）
LICENSE           利用条件
style.css         読み込み画面とボタンの見た目
docs/
  requirements.md 要件定義書
src/
  main.js         起動、毎フレームの更新
  walker.js       歩行者と灯り
  effects.js      濡れた路面、雨、光のにじみ
  audio.js        環境音の合成（雨、街、足音、踏切、電車）
  controls.js     キーボード・マウス・タッチの入力
  quality.js      画質の段階と自動調整
  path.js         歩く道筋とループ、エリアの区間
  street.js       街並みの箱をまとめて描く共通処理
  random.js       種を固定した乱数（毎回同じ街にする）
  areas/
    neon.js       ネオン街
    houses.js     住宅街
    rails.js      線路沿い
```

## 使っているもの

- [Three.js](https://threejs.org/) 0.187.0（CDNから読み込み、バージョン固定）
- 画像・3Dモデル・音声のファイルは使わず、すべてコードで生成します（共有用画像 `og.jpg` を除く）
