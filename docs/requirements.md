# 深夜の街を歩く3D体験サイト 要件定義書

作成日: 2026-11-10

## 概要

灯りを持った歩行者が、雨の深夜の街を自動で歩き続けるブラウザ上の3D体験を作り、GitHub Pagesで公開する。訪問者は眺めているだけでもよく、操作すれば向きや速さを変えられる。言葉は置かず、光と音だけで見せる。

参考にするのは [What the water keeps](https://what-the-water-keeps.vercel.app/) の「暗さ・小さな灯り・静けさ」という空気感だけで、舞台・モチーフ・素材はすべて独自に作る。参考サイトは公開されている説明文しか確認できておらず、実際の画面や操作感は未確認のため、細部は制作中に実物と見比べて調整する。

| 項目 | 決定内容 |

## 体験仕様

訪問者が何もしなくても、歩行者は決まった道筋を一定の速さで歩き続ける。

1. **読み込み画面**：暗い背景にタイトルと「はじめる」ボタンだけを表示する。街の生成が終わるとボタンが押せるようになる。
2. **開始**：ボタンを押すと音が鳴り始め、ネオン街の入口から歩行が始まる。音はこの操作をきっかけに初めて再生する。
3. **歩行**：道筋に沿って自動で進む。カメラは歩行者の少し後ろ上から追い、手元の灯りが足元の濡れた路面を照らす。
4. **操作**：操作している間だけ訪問者の入力が優先され、手を離すと数秒かけて自動歩行に戻る。
5. **ループ**：線路沿いの終わりがネオン街の入口へつながり、切れ目なく歩き続ける。一周は3〜5分を目安とする。

### 操作でできること

| 操作 | PC | スマホ |
| --- | --- | --- |
| 見回す | マウスのドラッグ | 画面のスワイプ |
| 速さを変える・立ち止まる | ↑↓キーまたはW・Sキー、スペースで停止 | 画面の上下スワイプ、長押しで停止 |
| 道幅の中で左右に寄る | ←→キーまたはA・Dキー | 画面の左右端をタップ |
| 音の入・切 | 画面隅のボタン | 画面隅のボタン |

道から外れて自由に歩き回ることはできない。移動できるのは道幅の中だけとし、当たり判定を単純に保つ。

### 画面に表示するもの

- 読み込み画面のタイトルと開始ボタン
- 開始直後に数秒だけ出て消える操作ヒント
- 画面隅の音ボタンと、操作説明を開く小さなボタン
- WebGLが使えない端末向けの案内文

## エリア構成

歩くほど光が減っていき、最後に踏切の赤だけが残る。3エリアは光の量と色で差をつける。

| エリア | 光 | 主な要素 | 音 |
| --- | --- | --- | --- |
| 1. ネオン街 | 多い。ピンク・青・緑など多色 | 雑居ビル、袖看板、提灯、自動販売機、濡れた路面への映り込み | 雨音、街のうなり、ネオンのジーという音 |
| 2. 住宅街 | 少ない。暖色の窓明かりと白い街灯 | 低い家並み、塀、電柱と電線、まばらな窓明かり | 雨音、遠くの車、室外機の低い音 |
| 3. 線路沿い | ごく少ない。踏切の赤い点滅 | フェンス、線路、踏切、架線柱、ときどき通る電車 | 雨音、踏切の警報音、電車の通過音 |

- エリアの境目は曲がり角や短いトンネル状の暗がりでつなぎ、霧の色と濃さをゆっくり切り替える。
- 線路沿いの終わりで踏切を渡り、その先の暗がりを抜けるとネオン街の入口に戻る。
- 看板の文字は実在の店名や商標を使わず、読めない抽象的な図形や架空の文字にする。「言葉なし」の方針とも合う。
- 通行人や車は初回公開では置かない。動くものは雨、ネオンの明滅、踏切、電車に絞る。

## ビジュアルと音

画像・3Dモデル・音声のファイルは一切持たず、すべて実行時にコードで作る。見た目は写実ではなく、箱や板を組み合わせた簡素な形に光と霧で雰囲気を乗せる方向とする。

### ビジュアル

- **街並み**：箱・板・円柱の組み合わせで建物、看板、電柱、フェンスを作る。並びは乱数の種（シード）を固定して生成し、毎回同じ街になるようにする。
- **歩行者**：傘を差し、提灯のような灯りを持った簡素なシルエット。細部は描かず、歩く揺れだけを付ける。
- **光**：歩行者の灯りを主光源にし、ネオンや街灯は発光する面と少数の点光源で表す。光のにじみ（ブルーム）を後処理でかける。
- **路面**：濡れた地面にネオンと灯りが映り込む表現を入れる。この作品の見せ場とする。
- **雨と霧**：細い線の粒で雨を降らせ、路面に波紋を出す。遠くは霧で暗い紺色に溶かし、描画する範囲を狭く保つ。
- **配色**：背景はほぼ黒に近い紺。エリアごとにネオンの多色、窓の暖色、踏切の赤を主役の色にする。

### 音

ブラウザの音声機能（Web Audio API）で合成する。

- **常に鳴る音**：雨音（ノイズを加工）、街の低いうなり
- **エリアごとの音**：ネオンのジーという音、室外機、踏切の警報音、電車の通過音
- **足音**：歩く速さに合わせた、濡れた路面の足音
- **切り替え**：エリアの境目で音量をゆっくり入れ替える。音源の位置に応じて左右の聞こえ方を変える。
- 音楽は初回公開では入れない。

## 対応端末と性能

PCとスマホの両方で動かし、端末の性能に合わせて画質を3段階で自動的に切り替える。

| 画質 | 想定端末 | 内容 |
| --- | --- | --- |
| 高 | グラフィック性能の高いPC | 路面の映り込み、光のにじみ、雨と波紋をすべて有効 |
| 中 | 一般的なノートPC、新しめのスマホ | 映り込みを簡略化し、雨粒の数と解像度を減らす |
| 低 | 古めのスマホ | 映り込みと光のにじみを切り、霧を濃くして描画範囲を狭める |

- **目標**：PCで毎秒60コマ、スマホで毎秒30コマ以上。開始ボタンが押せるまで3秒以内（通常の回線）。
- **自動調整**：開始後しばらくコマ数を測り、目標を下回れば画質を1段階下げる。
- **画面の向き**：スマホは縦・横どちらでも見られるようにする。
- **対応ブラウザ**：Chrome、Safari、Edge、Firefox の最新版。
- **配慮**：端末で「視差効果を減らす」が有効な場合は、カメラの揺れとネオンの明滅を弱める。踏切の点滅は激しい速さにしない。
- **省電力**：タブが裏に回ったら描画と音を止める。

## 技術構成と公開

ビルド工程を持たず、リポジトリに置いたファイルがそのまま公開される構成にする。

- **描画**：Three.js。importmap でバージョンを固定してCDNから読み込む。
- **言語**：素のJavaScript（ESモジュール）。フレームワークやパッケージ管理は使わない。
- **音**：Web Audio API。
- **公開**：GitHub Pages を main ブランチのルートから配信する。GitHub Actions は使わない。
- **公開URL**：`https://haloyukka.github.io/after-the-last-train/`。パスはすべて相対パスで書く。

### ファイル構成（案）

```
/
├── index.html          画面の枠、読み込み画面、importmap
├── style.css           読み込み画面とボタンの見た目
├── README.md
├── LICENSE
├── docs/
│   └── requirements.md この要件定義書
└── src/
    ├── main.js         起動、毎フレームの更新
    ├── path.js         歩く道筋とループ
    ├── walker.js       歩行者と灯り
    ├── controls.js     キーボード・マウス・タッチの入力
    ├── quality.js      画質の段階と自動調整
    ├── audio.js        環境音の合成
    ├── effects.js      雨、霧、路面の映り込み、光のにじみ
    └── areas/
        ├── neon.js     ネオン街
        ├── houses.js   住宅街
        └── rails.js    線路沿い
```

エリアは1ファイル1エリアにし、後からエリアを足しやすくする。

### 制約と注意

- ESモジュールはファイルを直接開くと動かないため、手元での確認には簡易サーバー（例：`python -m http.server`）を使う。
- CDNが止まると表示できなくなる。気になる場合は Three.js のファイルをリポジトリに同梱する方式に切り替えられる。
- GitHub Pages は静的ファイルのみで、サイト全体1GB・1ファイル100MBが上限の目安。今回は素材ファイルを持たないため、全体で数百KB程度に収まる見込み。
- 共有時の見栄えのため、タイトル・説明文・共有用画像（OGP）を設定する。共有用画像だけは完成後の画面を撮った画像ファイルを1枚置く。

### 実装で要件から変えた点

- 踏切では、電車の通過を待って立ち止まる（自動で歩き続けると電車にぶつかるため）。電車は周回ごとに1本通る。
- 立ち止まる操作は、PCではスペースの切り替え式、スマホでは長押しの間。PCはホイールでも速さを変えられる。
- 自動販売機や踏切の遮断機などの小物はコードで生成した箱の組み合わせ。通行人と車の姿は置いていない（車は音のみ）。
- ファイル構成に `src/street.js`、`src/random.js`、`og.jpg`、`.nojekyll` を追加した。

### 制作の進め方

動くものを早く公開し、段階ごとに見た目を足していく。

1. **土台**：リポジトリ作成、GitHub Pages 有効化、道筋に沿ってカメラが自動で進みループするところまで。建物は仮の箱。
2. **ネオン街**：歩行者と灯り、濡れた路面、雨、霧を入れ、1エリアで雰囲気を固める。ここで見た目の方向性を確認する。
3. **残り2エリア**：住宅街と線路沿い、エリアのつなぎ、踏切と電車。
4. **音**：環境音、足音、エリアごとの切り替え。
5. **操作と画質**：キーボード・マウス・タッチの操作、画質3段階と自動調整、スマホ実機での確認。
6. **仕上げ**：読み込み画面、操作ヒント、共有用画像、README。

### 完成の条件

- 公開URLをPCとスマホで開き、開始ボタンから3エリアを一周してネオン街に戻れる
- 何も操作しなくても歩き続け、操作後は自動歩行に戻る
- 目標のコマ数（PC 60、スマホ 30以上）を満たす
- 音の入・切ができ、タブを裏に回すと止まる
- 外部の画像・モデル・音声ファイルを使っていない（共有用画像を除く）
